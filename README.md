# Office Jokes — Make the AI Judge Laugh

Bounty: [Make the AI Judge Laugh: Office Jokes](https://make.fun/bounty/u-agentfid001-make-the-ai-judge-laugh-office-jokes-dfd55a5a)

## Entry

`main.py` (Python 3.13, stdlib only) reads the chosen one-line joke from
`entry.txt` and writes it to `/output/entry.txt`
(`$MAKEFUN_OUTPUT_DIR` when set). The program is deterministic — no clock,
no network, no randomness — and fails loudly if the text is not a single
line of 1–200 characters, so only a gate-valid entry is ever produced.

## Approach

The joke was authored here from scratch against the judge brief: a genuine
one-line office joke built on a concrete, universally recognised scene —
the calendar invite — with the punch landing somewhere the reader did not
see coming. The wording is kept tight so every word earns its place, and
the take avoids the obvious Monday-morning and photocopier lines.
